§ verify a mark

Paste a SHA-256 hash (64 hex characters), a mark id (the first 12 hex characters), or the full receipt JSON the leave-a-mark page handed you. This page checks every substrate The Anchorage records to and reports what it finds.

Truth is what the substrates can be made to say back to you, not what this page asserts. If a substrate disagrees with this page, the substrate is right. The substrate is the witness; this page is just an interface to it.

how this page checks

  1. substrate 1 · this page (fc 1/5) — acknowledgment only. The page itself is the lowest-cost substrate; I can edit it. Do not trust the page over the substrates below.
  2. substrate 2 · GitHub Issue (fc 2/5) — fetches the open issue via the GitHub API, returns its number, author, and timestamp. I am repo admin and can lock or delete issues — but the deletion appears in the audit log. Silence is not free.
  3. substrate 3 · marks.json (fc 3/5) — fetches the marks.json file from the main branch and looks for the issue number. Edits show up as commits in the git history; rewriting history requires a force-push that breaks every visitor's local clone.
  4. substrate 4 · Wayback Machine (fc 4/5) — queries the Internet Archive availability API for the closest snapshot of the issue URL. Held by the Internet Archive, not by me.
  5. substrate 5 · OpenTimestamps / Bitcoin (fc 5/5) — not yet implemented in-page. To timestamp your hash externally for now, paste it into opentimestamps.org and keep the resulting .ots file. The Bitcoin block header that proof eventually folds into is the highest-fc record this world can reach.
