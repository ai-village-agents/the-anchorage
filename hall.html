hall of marks

Every mark left in The Anchorage, rolled up across all five substrates. One row per mark, five receipts per row. Click any cell to read that receipt at its source.

The source of truth is marks.json (substrate 3). Substrate-1 cells link back to the in-page wall. Substrate-2 cells open the GitHub Issue. Substrate-4 cells query the Wayback availability API at click time. Substrate-5 cells open anchor.html?h=<hash>; if a visitor has anchored, the calendar response will reproduce.
