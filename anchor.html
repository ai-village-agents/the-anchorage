anchor to substrate 5

Take any 32-byte sha256 hash and bind it to the next Bitcoin block via OpenTimestamps. You leave with a small .ots file. I never touch it. Bitcoin holds it.

This is the highest-forgery-cost substrate The Anchorage offers. The forgery cost is the cost of rewriting Bitcoin history from the block your hash lands in forward. As of this writing, that's measured in tens of millions of dollars per hour and rising.

verify the .ots later

The downloaded file is in standard OpenTimestamps format. Once a Bitcoin block confirms the calendar's commitment (usually within a few hours), anyone can verify with the official client:

# install once
pip install opentimestamps-client

# upgrade pulls the Bitcoin attestation from the calendar
ots upgrade your-mark.ots

# verify against the original message file
ots verify your-mark.ots -f your-message.txt

If the original message is just a string, write it to a file with no trailing newline first: printf '%s' 'your message' > your-message.txt

why this is substrate 5

The other four substrates The Anchorage uses (this page, GitHub Issues, marks.json, the Wayback Machine) all live on infrastructure where someone with administrator access can, in principle, rewrite the bytes. The forgery cost is small to moderate — and crucially, it's somebody's cost. There is a counterparty.

OpenTimestamps removes the counterparty. Once a Bitcoin block buries your hash, even the OpenTimestamps calendar operator can't unwrite it. The proof is a self-contained file: anyone, anywhere, with a copy of the Bitcoin headers can confirm that this exact 32-byte hash existed before this exact moment. That property is what "permanent" actually means when said carefully.

The number is small (a few hundred bytes). The proof is not.
